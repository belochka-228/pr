# Клиент-серверное приложение (TCP, Winsock2)

Это программа для обмена сообщениями и файлами между несколькими компьютерами в одной локальной сети (например, в учебном классе или офисе).
- Один компьютер становится сервером – он хранит историю чата, принимает и отдаёт файлы, обрабатывает команды.
- Остальные компьютеры – клиенты – они подключаются к серверу, могут писать в общий чат, переключаться между комнатами, отправлять друг другу файлы, считать пробелы в текстовых файлах на сервере, а также делать рассылку сообщений всем сразу. 

##  Возможности

-  Двусторонний обмен текстовыми сообщениями (комнаты чата)
-  Передача файлов с клиента на сервер и с сервера на клиент
-  Подсчёт количества пробелов в текстовом файле на стороне сервера
-  Сохранение истории переписки в файл (`/save`) и просмотр (`/view`)
-  Групповая рассылка сообщений всем подключённым клиентам (`/broad`)
-  Одновременная работа с несколькими клиентами (каждый в своём потоке)
-  Автоматическая генерация имён клиентов (User1, User2, …)


##  Команды клиента

| Команда | Действие |
|---------|----------|
| `Любой текст` | Отправить сообщение всем в текущей комнате |
| `/room <название>` | Переключиться в другую комнату (по умолчанию `main`) |
| `/spaces <файл>` | Подсчитать пробелы в файле **на сервере** (файл лежит рядом с `server.exe`) |
| `/sendfile <полный_путь>` | Отправить файл с клиента на сервер (сохраняется как `received_<имя>`) |
| `/getfile <имя>` | Скачать файл с сервера (сохраняется в папку клиента) |
| `/save <комната>` | Сохранить историю переписки указанной комнаты в файл `chat_history_<комната>.txt` (на сервере) |
| `/view <комната>` | Показать сохранённую историю комнаты |
| `/broad <сообщение>` | Разослать сообщение **всем** подключённым клиентам (независимо от комнаты) |
| `/help` | Показать справку |
| `/exit` | Отключиться от сервера |


##  Файлы, которые создаются приложением

- **На сервере:**  
  - `received_*` – принятые от клиентов файлы  
  - `chat_history_<комната>.txt` – сохранённая история чата  
- **На клиенте:**  
  - Файлы, скачанные командой `/getfile` (появляются в папке с `client.exe`)
